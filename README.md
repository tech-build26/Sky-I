# Sky I website

Independent Next.js application in `web/`. Repository: https://github.com/tech-build26/Sky-I.

Install with `npm --prefix web ci`, then run `npm run dev` from this folder. Local origin: http://localhost:3006/. `npm run build` and `npm run start` run the production app.

The root is this brand's pre-landing; its current-brand choice opens `/home/`. The other brand opens its separate root pre-landing. Sky I is left and Skyriders right on Sky I; Skyriders is left on Skyriders. Both local servers must run for local handoffs. Local overrides are ignored and must be removed before packaging.

No sibling-folder imports, shared runtime or brand environment selector is required. Both projects carry their own fonts, pre-landing assets and dependencies. Preserved original research and asset history in Ropeaccess is not public website content. Deployment still requires Afrihost runtime confirmation and owner upload. See `docs/site-split.md`.
