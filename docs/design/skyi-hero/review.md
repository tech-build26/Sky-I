## Motion

One persistent subject interpolates four section poses in position, scale and roll using native reversible scroll. Pointer motion is bounded to 50px horizontally/30px vertically and settles with interpolation; a perspective transform tilts the supplied image plane. A separate small station-keeping movement pauses on keyboard focus, document hiding or the motion control. The control stops ambient/pointer movement; native scroll still positions the subject alongside content. Mobile uses reserved content-relative destinations. The actual current section is shown in the corner and the matching navigation link receives `aria-current="location"`.

This is spatial 2D image presentation, not a true 3D Elios or an all-angle orbit. Inventory found the supplied PNG, its existing derivatives and no GLB/GLTF model. Genuine rotation needs an accurate authorised model/multi-angle source; S03-M remains open. No model, equipment, scans, telemetry or payload capabilities were fabricated. No new dependency or mechanically generated image asset was needed.

Reduced motion and no JavaScript keep the supplied drone static in the hero and retain semantic copy and anchors. A live preference change restores a usable static state and can re-enable flight. Image failure leaves navigation and copy usable.
