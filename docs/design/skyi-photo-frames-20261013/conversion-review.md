# Landing conversion audit — 13 October 2026

Owner requests a brief hero-to-footer assessment of conversion readiness, typography and improvement opportunities. Review only; no product redesign or application change is authorised by this request.

Evidence: current localhost:3006/home/ content and computed font/layout inspection at 1440, 390 and 740px; current desktop/mobile section screenshots audit-*.png and conversion-audit.json. Screenshots use reduced motion, showing settled content and all static sample quotes. Their long-page measurements therefore do not establish normal-motion page lengths. Development inspection is not a production speed or real conversion measurement. No section/document horizontal overflow was measured at the inspected widths. Earlier N15 verification retains native/control/static/failure evidence; this audit does not replace integrated acceptance.

Verdict: strong visual identity, service choices, real field imagery and a useful planning interaction, but high conversion is unproven. Current gaps are real proof, direct enquiry delivery, prominent enquiry intent and purchase-decision information. There is no implemented analytics collector/conversion funnel in src; existing consent scaffolding is not measurement. Do not assign an invented conversion score or promise a lift.

| Area | Finding and recommendation |
| --- | --- |
| Hero/header | Equipment/service choices are clear. The question-led heading and exploratory description do not establish a specific buyer outcome/differentiator or offer a prominent direct enquiry action. Keep the composition; add one concise factual outcome line and an enquiry link. Test intro timing rather than assuming animation itself harms conversion. Projects is still a pending label; omit from public navigation until useful content exists. |
| About | Attractive, readable introduction, but duplicates service/site-question messages. Add confirmed company identity, service coverage and a concrete reason to choose the team. Generated setting images are identified as illustrations in alt text, not visibly in the tile captions; make their illustrative status clear to sighted visitors where retained. |
| Services | Native asset explorer and supplied photos work. Buyer information is still mainly applications and invitation language. Specify confirmed deliverables, scope boundaries and the next step after enquiry; do not invent report products, turnaround or equipment capability. |
| Sectors | Strong context selection, but repeats questions about the asset. Make each response identify the relevant application/maintenance decision without adding unsupported claims. |
| Safety/preparation | Useful live brief with real team photograph. Needs a succinct agreed process: site discussion, suitability/access agreement, inspection, agreed handover. Keep the existing suitability qualifications; add credentials only when verified for the correct entity. |
| Practical-next-step CTA | Good visual invitation but echoes hero/About. Align its action with a single enquiry objective and state what the visitor will discuss next. |
| Client confidence | All nine quotes are explicitly fictional design samples. They supply no real trust evidence and should be replaced or omitted for publication. Use consented actual quotes or approved anonymised project context/outcomes; restricted client identity stays excluded. |
| Contact | Four fields and direct email/phone are useful. The form only opens a mailto draft and cannot confirm receipt. Implement actual server delivery after host/provider agreement, with genuine success/failure feedback and an honest next-step explanation. |
| Footer | Clear offices/contacts/sister/social ownership. Add the agreed privacy/data-handling destination and reinforce the company relationship around the shared ropeaccess.co.za email if needed; do not invent another recipient. |
| Typography/flow | Keep Cormorant/Jost and the blue/mineral palette. Computed small labels include 9.28, 9.6, 10.24 and 11.52px on mobile; increase useful labels/captions, reduce excessive tracking and keep body copy around 16–18px where practical. Large serif italics work as emphasis but repeated title/copy patterns diminish hierarchy. Shorten repeated copy and mobile decorative/gallery height where it does not add buyer information. No blanket font replacement is justified. |

Priority: real enquiry delivery, genuine proof and a clear hero enquiry action; then buyer information/FAQ, typography/page economy and measurement. Measure qualified received enquiries, calls and service-to-contact progression. Production mobile Core Web Vitals remain unmeasured here; Q03 stays open. Actual conversion depends on audience/traffic quality and needs measured outcomes and comparison, not a design impression.

Primary UX reference: https://www.nngroup.com/articles/homepage-design-principles/ supports immediate purpose/value, examples and clear priority actions. Performance measurement reference: https://web.dev/articles/vitals. Recommendations are an assessment of this page, not a claim that those sources predict this site's conversion rate.
