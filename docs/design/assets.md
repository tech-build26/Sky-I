## 3. Responsive Delivery Rules

- **Web Fonts**: `web/src/app/layout.tsx` imports `jost.woff2` and `cormorant.woff2` using Next.js `localFont`. Payload reduced from 1.33 MB to 128.2 KB (90.4% reduction) with variable font weights and OpenType features preserved.
- **Cutouts & Marks**: Transparent PNG master assets are complemented by WebP and optimized PNG responsive sizes (1024/768/480/320 for technician, 1600/1024/640/400 for Elios 3, 328/164/105 for Skyriders logo, 274/137/88 for Sky I logo). `<Image>` tags use explicit `sizes` definitions.
- **Backdrop Photography**: Background hero images are delivered via responsive CSS `image-set()` in `globals.css` with WebP and JPEG fallbacks (1916/1672, 1280, 768, 480). Mobile devices load 23–32 KB instead of 500–600 KB masters.
