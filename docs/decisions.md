- Hero copy removes the draft's universal weeks/hours/3D-delivery assertions. That page also qualifies ingress protection and reports flight time differently from the supplied draft, reinforcing the decision to publish no numerical specs now.

- Implementation consulted official [Lenis integration documentation](https://github.com/darkroomengineering/lenis) and [GSAP ScrollTrigger documentation](https://gsap.com/docs/v3/Plugins/ScrollTrigger/), plus installed version-matched Next.js font/metadata guides.
